Security Policy
Supported Versions

Unnamed-DE is currently under active development. Security fixes are provided for the latest version available on the main branch.

Version	Supported
Latest (main)	Yes
Older versions	No
Reporting a Vulnerability

If you discover a security vulnerability in Unnamed-DE, we appreciate your help in reporting it responsibly.

Please do not report security vulnerabilities through public GitHub Issues or Pull Requests.

Instead, please use GitHub's private vulnerability reporting feature through the repository's Security tab, if available.

If private vulnerability reporting is unavailable, contact the project maintainers privately through GitHub.

When reporting a vulnerability, please include:

A brief description of the issue.
The affected file or component, if known.
Steps to reproduce the issue.
The potential impact.
Relevant screenshots or logs, if applicable.
Security Guidelines

To help keep Unnamed-DE safe and maintainable, contributors should follow these guidelines:

1. Code Security
Avoid introducing unnecessary security risks.
Validate user input where applicable.
Handle errors safely without exposing sensitive information.
Review code before submitting pull requests.
2. Sensitive Information
Never commit passwords, API keys, access tokens, or private credentials.
Keep sensitive configuration outside the source code.
Remove accidentally exposed secrets and rotate compromised credentials.
3. Dependencies
Use trusted and maintained dependencies.
Avoid unnecessary third-party packages.
Update dependencies when security vulnerabilities are discovered.
4. Contributions
Do not intentionally introduce malicious code.
Explain security-relevant changes in pull requests.
Report suspicious code or unexpected behavior to maintainers.
Responsible Disclosure

We ask security researchers and contributors to:

Give maintainers reasonable time to investigate reported issues.
Avoid publicly disclosing vulnerabilities before they are addressed.
Avoid accessing or modifying data that does not belong to them.
Avoid destructive testing or service disruption.
Respect the privacy of other contributors and users.
Scope

This policy covers security issues directly related to Unnamed-DE, including its source code, build scripts, dependencies, and repository configuration.

Disclaimer

Unnamed-DE is a small, community-driven project that is actively being developed and improved.

While we take security seriously, we cannot guarantee that the project is completely free from vulnerabilities.

Thank you for helping make Unnamed-DE safer for everyone.
